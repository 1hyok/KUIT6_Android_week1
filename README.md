# KUIT6 Android week 1 practice

KUIT 6기 Android 1주차 실습을 위한 Kotlin 저장소입니다.

## 실행

Android Studio에서 저장소를 열고 Gradle 동기화 후 `app` 모듈을 실행하세요. Android SDK 경로는 로컬 환경에 맞게 설정합니다.

```sh
./gradlew :app:assembleDebug
```

## 상태

수업 실습 기록입니다. 기존 README의 upstream 저장소 안내가 이 저장소 설명과 일치하지 않아, 이 문서는 현재 저장소의 목적과 실행 경로를 기준으로 정리했습니다.
